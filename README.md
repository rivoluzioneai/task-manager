# Task Manager

Applicazione web per la gestione di note personali, costruita con Flask e SQLite.
Ogni utente si registra con username e password e gestisce le proprie note in modo
privato (creazione, modifica, eliminazione).

## Requisiti

- Python 3.9 o superiore
- pip

## Installazione

```bash
# 1. Clona il repository
git clone https://github.com/rivoluzioneai/task-manager.git
cd task-manager

# 2. Crea e attiva un ambiente virtuale
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Installa le dipendenze
pip install -r requirements.txt
